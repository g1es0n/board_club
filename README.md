# Система учёта клуба настольных игр

Система ведёт каталог игр, игроков и сыгранных партий, автоматически считает рейтинг игроков
и формирует отчёты. Основная бизнес-логика реализована на стороне MySQL: триггеры,
хранимые процедуры, транзакции, представления и разграничение прав на уровне пользователей СУБД.

## Возможности

- Каталог игр с фильтрами по жанру и числу игроков
- Справочник столов с описанием (номер можно не указывать, тогда он равен id)
- Регистрация игроков, история партий, деактивация и повторная активация без потери истории
- Баны игроков с указанием причины: временный (игрок остаётся в рейтинге, но не может
  попасть в партии до окончания бана) и полный (игрок деактивируется и скрывается из рейтинга)
- Партии: создание, состав участников, ввод очков, завершение с пересчётом рейтинга
- Перенос запланированной партии: новое время, стол и состав участников
- Отметка посещаемости у идущей или завершённой партии
- Календарь партий по неделям
- Проверки на уровне БД: занятость стола, свободные копии игры, участие игрока
  в пересекающихся по времени партиях, действующий бан
- Отчёты: топ игроков, популярность игр, загрузка столов по дням недели, карточка игрока
- Публичная страница рейтинга без входа в систему

## Стек

- MySQL 8.0
- Python 3.12, FastAPI, PyMySQL
- HTML, Bootstrap 5, JavaScript (fetch)
- Docker Compose

## Запуск

1. Установите [Docker Desktop](https://www.docker.com/products/docker-desktop/).
2. Скопируйте `.env.example` в `.env`:

```
   copy .env.example .env
```

   На macOS и Linux: `cp .env.example .env`

3. Запустите:

```
   docker compose up -d --build
```

4. Откройте http://localhost:7999

Документация API (Swagger): http://localhost:7999/docs

Остановить: `docker compose down`.
Пересоздать базу с нуля: `docker compose down -v`, затем снова `docker compose up -d --build`.

## Учётные записи

Пользователи MySQL (подключение к базе в Docker: `127.0.0.1`, порт `3307`):

| Пользователь | Пароль      | Права                                              |
|--------------|-------------|----------------------------------------------------|
| root         | rootpass    | Полный доступ к серверу                            |
| club_admin   | admin_pass  | Полный доступ к базе `board_club`                  |
| club_host    | host_pass   | Игроки и партии, чтение справочников, процедуры    |
| club_viewer  | viewer_pass | Только представления публичного рейтинга           |


Рейтинг: начальное значение 1000, после партии из N участников игрок на месте P получает
изменение ΔR = 5 · (N − 2P + 1). Места уникальны: при равенстве очков выше ставится игрок
с меньшим id, поэтому сумма изменений рейтинга в партии всегда равна нулю.

```

backend/app/main.py    точка входа FastAPI
backend/app/routers/   эндпоинты API (каталог, игроки, партии, календарь, отчёты)
backend/app/schemas.py модели запросов и их валидация
backend/app/db.py      подключение к MySQL
backend/app/auth.py    вход, пароли, проверка ролей
backend/app/errors.py  обработка ошибок
backend/static/        клиентская часть
docker-compose.yml     запуск MySQL и приложения
```
